이용약관 홈으로

RayTok 개인정보 처리방침

시행일 2026-10-03 · 적용: RayTok Ear (com.raytok.ear), RayTok Glass (com.raytok.glass)

RayTok은 실시간 통역 앱입니다. 이 문서는 앱이 휴대폰 안에 저장하는 것과 휴대폰 밖으로 보내는 것을 빠짐없이 적은 것입니다. 분석·광고 SDK는 쓰지 않으며, 계정·가입·결제 정보를 받지 않습니다.

1. 휴대폰 안에 저장하는 것

무엇어디얼마나지우는 방법
메모 — 강연·메모·저장한 대화의 원문과 번역앱 전용 저장 공간사용자가 지울 때까지메모 삭제, 또는 설정 → 앱 초기화
활동 기록 — 세션 시작·끝 같은 줄앱 전용 저장 공간, 최근 60줄밀려날 때까지앱 초기화
설정 — 언어, 출력, 스위치, 번역 엔진, 휴대폰 이름앱 전용 저장 공간지울 때까지앱 초기화
인식 기록 — 음성 인식기가 준 원문·시각·설정 값 (진단용)메모리. 사용자가 "기록 저장"을 누르면 메모로앱을 끄면 사라짐. 저장하면 메모와 같음기록 지우기, 앱 초기화
번역 모델 (언어당 30~80MB)앱 전용 파일지울 때까지설정 → 언어 팩 → 삭제
가이드 사용 기록 — 세션 코드·시작/끝 시각·참여자 수·언어별 수앱 전용 저장 공간, 200개까지밀려날 때까지앱 초기화
이 휴대폰의 임의 식별자 — 설치할 때 앱이 스스로 만드는 무작위 값앱 전용 저장 공간지울 때까지앱 초기화
번역 중계 이용권(토큰)과 유효기간앱 전용 저장 공간다시 받을 때까지앱 초기화
사용자가 입력한 본인의 번역 API 키앱 전용 저장 공간지울 때까지설정에서 비우기, 앱 초기화
이어폰 이름 — 전에 LE Audio로 연결된 적이 있는지 (연결 안내용, 최대 8개)앱 전용 저장 공간지울 때까지앱 초기화
참석 기록 — 이름·선택 언어·접속 시각진행자(강사/호스트) 화면에만 표시, 중계 서버 보관 없음세션 종료 시 즉시 삭제 (진행자가 로컬 파일로 저장한 경우 진행자 PC에만 보관)세션 종료
Desk 회의 기록 — 화상회의 양방향 자막 및 해시 체인 무결성 기록중계 서버 (보관함)기본 30일 (DESK_KEEP_DAYS 경과 시 자동 영구 삭제)웹 뷰어(web/desk) 상세 화면에서 '기록 삭제' 단추로 이용권 소유자가 즉시 영구 삭제

음성 인식 모델은 휴대폰의 구글 음성 서비스가 관리하며 앱 밖에 있습니다. 안드로이드 자동 백업은 꺼져 있습니다. 위 항목은 구글 계정으로 백업되지 않으며, 휴대폰을 바꾸면 따라가지 않습니다.

대화·강연·가이드의 내용은 기본적으로 저장되지 않습니다. 사용자가 "메모에 저장"을 누른 것만 남습니다.

2. 휴대폰 밖으로 보내는 것

쓰는 방식에 따라 다릅니다. 네 경우로 나누어 적습니다.

  • 언어 팩을 받아 두고 인터넷 없이 쓸 때 — 음성과 번역이 휴대폰 안에서 처리되고 밖으로 나가지 않습니다.
  • 인터넷에 연결된 채로 쓸 때 — 음성 인식은 구글 음성 서비스로, 번역은 구글 번역으로 전달됩니다.
  • 가이드·RayTok Desk — 참석자에게 전달하기 위해 중계 서버를 거칩니다.
  • 기기 번역 모델이 없는 언어로 번역할 때 — 일부 언어는 휴대폰 안에서 번역할 수 없습니다 (설정 → 언어 팩에서 "서버 번역" 으로 표시되는 언어입니다). 이 언어가 섞인 세션에서는 강의 원문과 번역문이 외부 번역 서버로 전송됩니다.
    (그중 일부는 읽을 수 있는 다른 언어로 휴대폰 안에서 처리할 수 있고 그때는 전송되지 않습니다 — 네팔어→힌디어, 라오어→타이어, 아제르바이잔어→터키어, 테툼어→인도네시아어, 몽골어·키르기스어·타지크어·카자흐어→러시아어. 그 밖의 언어는 대체가 없어 전송됩니다.)
    설정에서 "서버로 보내지 않음" 을 고르면 아무것도 전송하지 않습니다. 그때 대체가 없는 언어는 번역되지 않고 그 사실을 화면에 알립니다.
무엇어디로언제
번역할 문장(원문 텍스트)RayTok 번역 중계 서버를 거쳐 구글 번역휴대폰에 그 언어 짝의 모델이 없을 때, 또는 번역 엔진을 "인터넷 번역"으로 두었을 때
번역할 문장(원문 텍스트)구글 번역 (translation.googleapis.com) — 사용자 본인의 키로 직접사용자가 설정에 본인의 번역 API 키를 넣었을 때. 이 경우 중계 서버를 거치지 않습니다
음성(오디오)휴대폰의 구글 음성 인식 서비스 — 기기 내 모델이 있으면 휴대폰 안에서, 없으면 구글 서버로기기 내 인식 모델이 없는 언어를 들을 때 (안드로이드가 보냅니다)
이 휴대폰의 임의 식별자RayTok 번역 중계 서버번역 중계 이용권(토큰)을 받을 때. 1회이며 통역 내용은 함께 가지 않습니다
연결 정보 — 주소·참가 코드·언어raytok.kr상대가 QR을 찍을 때. 찍은 휴대폰의 브라우저가 그 안내 페이지를 먼저 엽니다. 휴대폰 이름은 보내지 않습니다
대화·강연 한 줄(원문+번역)투폰 상대 휴대폰 / 가이드 참석자 — 같은 근거리망, 암호화 없음투폰·가이드 연결 중. RayTok 서버를 지나지 않습니다

구글로 보낸 문장·음성의 처리는 Google 개인정보처리방침을 따릅니다. RayTok 중계 서버는 번역을 전달하기 위한 통로이며, 통역 내용을 보관하지 않습니다.

인터넷 없이 쓰려면 설정 → 언어 팩에서 언어를 미리 받고, 번역 엔진을 "기기 내 우선"으로 두면 됩니다. 투폰·가이드는 공용 Wi-Fi보다 한쪽 휴대폰의 핫스팟을 권합니다.

3. 앱이 요구하는 권한

  • 마이크 — 음성 인식
  • 블루투스 연결 — 이어폰·안경으로 소리 보내기, 이어폰 마이크 사용
  • 인터넷 — 번역, 언어 팩 받기
  • 카메라 — 글자 번역(카메라로 찍은 글자 읽기), 투폰·가이드 연결 QR 찍기
  • 알림 — 통역 중에 세션이 끊기지 않도록 알림 한 줄을 띄웁니다(화면을 꺼도 계속 듣기 위해 필요합니다). 그 알림을 누르면 앱으로 돌아와 멈출 수 있습니다

그리고 사용자에게 묻지 않고 자동으로 허용되는 것 둘이 더 있습니다 — 포그라운드 서비스(통역 중에 알림 한 줄로 세션을 살려 둡니다. 마이크를 쓰는 모드는 "마이크", 소리만 내는 모드는 "미디어 재생"으로 선언합니다)와 절전 해제(화면이 꺼진 동안 인식이 멈추지 않게 합니다). 위치·주변 기기 검색 권한은 쓰지 않습니다.

4. 사용자가 할 수 있는 것

  • 설정 → 앱 초기화: 1항의 항목 전부 삭제(인식 기록·저장한 키 포함)
  • 메모 화면에서 메모 개별 삭제, 언어 팩 화면에서 모델 삭제
  • 번역 엔진을 "기기 내 우선" 으로 두고 언어 팩을 받아 두면 번역이 밖으로 나가지 않습니다
  • 휴대폰을 넘기기 전에는 앱 초기화 또는 앱 삭제를 권합니다

5. 아동·민감정보

RayTok은 아동을 대상으로 하지 않으며, 별도의 계정·가입·결제 정보를 받지 않습니다. 통역 내용은 사용자가 말한 그대로이며, RayTok 운영자는 통역 내용을 보관하지 않고 볼 수 없습니다. 삭제를 요청할 내용이 운영자 쪽에 남지 않습니다. 다만 번역 중계를 쓰는 판에서는 2항의 임의 식별자가 중계 서버에 1회 전달되며, 그 삭제는 아래 문의처로 요청할 수 있습니다.
