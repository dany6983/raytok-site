# 범용 마케팅 엔진 v1 (2026-10-31)

제품을 갈아 끼우는 구조다. **제품 추가 = `products/<id>.json` 하나 더.** 엔진 코드는 건드리지 않는다.

```
products/*.json  ← 제품 사실·금지어·소재·채널·한도
       ↓
   route.mjs     ← 날짜 배치 · 금지어 게이트 · 한도 계산
       ↓
  out/plan-*.json ← 발행 계획 (사람이 읽고, MCP 도구가 발행)
       ↓
  quota/YYYY-MM.json ← 무료 한도 사용량 · 쓴 소재 기록
```

## 쓰는 법
```bash
node route.mjs plan  raytok-app  2026-11 1 2   # 주1회 화요일
node route.mjs plan  raytok-glass 2026-11 1 5   # 주1회 금요일
node route.mjs quota 2026-11
node route.mjs check raytok-app "검사할 문구"
```

## 왜 이렇게 짰나

**1. 금지어 게이트가 발행 앞에 선다.**
「특허받은」「인터넷 없이」「동시통역」 같은 말이 나가면 광고법 문제가 된다.
제품마다 금지어가 다르다 — 「구독료 없음」은 선글라스엔 사실이고 현장교육(1인 월 1만원)엔 거짓이다.
`_common-forbidden.json` 에 공통, 제품 JSON 에 추가분. 대체 문구까지 같이 돌려준다.

**2. 출처 없는 숫자를 잡는다.**
소재에 쓴 숫자가 제품 `facts` 에 없으면 「출처 확인 필요」로 표시한다. 지어낸 숫자가 나가는 걸 막는다.

**3. 무료 한도를 채널 수로 곱해서 센다.**
Metricool 무료는 월 20건인데 **채널마다 1건**이다. 인스타+페북에 올리면 한 편이 2건.
선글라스와 앱이 같은 브랜드를 쓰므로 계획끼리도 서로 자리를 먹는다 (`plannedElsewhere`).

**4. 쓴 소재는 3개월간 다시 안 나온다.**
`quota/*.json` 로그를 거슬러 읽어 중복을 뺀다.

## 발행 도구 분담 (무료, 2026-10-31 결정)
| | Metricool 무료 | Upload-Post 무료 |
|---|---|---|
| 담당 | RayTok (선글라스 + 앱) | 터치톡 |
| 월 한도 | **20건** | **10건** |
| 계정 | 네트워크당 1개 | 프로필 2개 |
| 넘으면 | 예약은 되나 **발행 안 됨** (1일 리셋) | 업로드 거부 |
| 못 쓰는 것 | 링크드인·X | — |

Metricool 무료는 **브랜드를 늘릴 수 없다.** 그래서 터치톡을 같이 못 넣는다. 나누는 수밖에 없었다.

## 배분 (월 20건 기준)
- 앱(B2B 릴스) 화요일 주 1회 × 2채널 = 8건
- 선글라스 금요일 주 1회 × 2채널 = 8건
- 예비 4건 (돌발 소재·재발행)

주 5회는 무료로 안 된다. 한 편을 제대로 만드는 쪽으로 간다.

## 안 하는 것
- 자동 DM · 팔로우봇 · 가짜 참여. 메타가 계정을 죽인다 (터치톡 광고계정 제한 전력)
- 개인 휴대폰·개인 이메일 수집
- 경쟁사 실명 (대외 소재)
