# RayTok 상세 4장 — 「고치는 길」 실증 (2026-11-09 17시, claude-22)

16시에 **내가 적은 길이 반쯤 틀렸다.** 「`img/d3/page.html` 로 다시 뽑으면 커밋으로 끝」이라
적었는데, 라이브가 부르는 이름은 `img/d2/RT18G_N_pN.jpg` 이고 렌더러가 뱉는 이름은
`img/d3/RT18G_v3_N.jpg` 다. **다시 뽑아 커밋해도 라이브는 안 바뀐다.**

## 1. 라이브 ↔ 레포 ↔ 렌더러, 세 겹을 다 맞댐

| 맞댄 것 | 결과 |
|---|---|
| 라이브 `raytok.kr/img/d2/*` ↔ 레포 `img/d2/*` | **네 장 모두 같은 바이트** (`f4947e20`·`028f47c8`·`216f2f0e`·`e12fc4d0`) |
| 레포 `img/d2/*` ↔ 레포 `img/d3/RT18G_v3_*` | **네 장 모두 같은 바이트** — 이름만 다른 같은 그림 |
| `page.html` 재렌더 ↔ 지금 `img/d2/*` | **네 장 모두 같은 바이트** — 렌더러가 라이브를 그대로 재현한다 |

→ **`img/d3/page.html` 이 라이브 상세의 진짜 원본이 맞다.** 다만 렌더러와 라이브 사이에
**손으로 베끼는 걸음(d3 → d2 이름)이 하나 끼어 있고, 그게 적혀 있지 않았다.**

- `img/d2/page.html` 은 **어느 커밋에도 없었다**(`git log --all` 0건)
- `RT18G_v3_*` 를 부르는 쪽·json·스크립트 **0건** — d3 렌더물은 아무도 안 쓴다
- 글꼴 가드가 막아 준다: Pretendard 4종이 없으면 렌더러가 **멈춘다**(조용히 다른 글꼴로 안 뽑힘)

## 3. 🔴 자리가 셋이 아니라 **넷**이었다

위 셋 말고 **FAQ 198줄**에 「언어팩을 한 번 **내려받으면** 그 뒤로 월 요금이 없습니다」가 또 있다.
월 요금 이야기라 글 자체는 맞지만, **내려받을 팩이 있다는 전제**는 오늘도 거짓이다(ready 0개).
고친판에선 **안 건드렸다** — 답이 달라지는 칸이라 대표님 판정으로 올린다.

## 5. 고치는 날 밟을 걸음 (대표님 결정 뒤)

```bash
npm pack pretendard && tar xzf pretendard-*.tgz          # 글꼴 (레포에 없다)
mkdir -p /root/.fonts && cp package/dist/public/static/Pretendard-{Regular,Medium,SemiBold,Bold}.otf /root/.fonts/
node tools/render-detail-d3.mjs                           # img/d3/RT18G_v3_N.jpg 가 나온다
cp img/d3/RT18G_v3_2.jpg img/d2/RT18G_2_p2.jpg            # ★ 베끼는 걸음 — 이게 빠지면 라이브 안 바뀜
```
