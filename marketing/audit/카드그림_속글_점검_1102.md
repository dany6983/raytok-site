## 덤으로 찾은 게이트 구멍 (고쳤다)

**증상.** 같은 말인데 캡션은 ✗, 그림은 ✓ 로 나왔다.

```
"월 구독료 0원"      → ✗ 금지어 「구독료 0원」
"월 구독료\n0원"     → ✓ 금지어 없음      ← 그림은 머리글을 줄로 쪼갠다
```

**까닭.** 금지어·통지어를 `indexOf` 로 찾고 있었다. 사이에 줄바꿈이 하나 끼면 다른 문자열이 된다.
법정 고지문 쪽은 **2026-11-01 에 이미** 공백에 느슨한 `looseRe` 로 옮겨 놨는데,
**금지어만 그대로 남아 있었다.** 카드 그림은 머리글을 거의 항상 두세 줄로 쪼개므로
**그림은 통째로 사각지대였다.**

**고친 것.** `lib/check.mjs` 한 파일. 금지어·통지어도 고지문과 같은 `looseRe('i')` 로 찾는다.
걸린 자리 앞뒤 15자는 줄바꿈을 한 칸으로 눕혀 읽기 좋게 했다.

- `\s+` 는 **공백·줄바꿈만** 잇는다. 「구독료. 0원」처럼 사이에 글자가 끼면 안 걸린다 — 확인함
- 홑낱말 금지어는 전과 똑같이 동작한다(이을 공백이 없다)
