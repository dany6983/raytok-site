## 1. 드리는 것 — 범용 마케팅 엔진

저장소: `github.com/dany6983/raytok-site` · 경로 `marketing/`

제품을 갈아 끼우는 구조입니다. **제품 추가 = `products/<id>.json` 하나 더.** 엔진 코드는 안 건드립니다.

```
products/*.json  →  route.mjs  →  out/plan-*.json  →  quota/YYYY-MM.json
```

```bash
node route.mjs plan  <productId> <YYYY-MM> <주당횟수> <요일>   # 발행 계획
node route.mjs quota <YYYY-MM>                                # 무료 한도 사용량
node route.mjs check <productId> "검사할 문구"                 # 금지어 검사
```

### 엔진이 막아주는 것 넷
| | |
|---|---|
| 금지어 | 공통(`_common-forbidden.json`) + 제품별. **대체 문구까지 돌려줍니다** |
| 출처 없는 숫자 | 소재의 숫자가 제품 `facts` 에 없으면 「출처 확인 필요」 표시 |
| 한도 초과 | 채널마다 1건으로 셉니다. 같은 도구를 쓰는 제품끼리 계획도 서로 자리를 먹습니다 |
| 소재 중복 | 쓴 후킹은 3개월간 다시 안 나옵니다 |

**금지어는 제품마다 다릅니다.** 「구독료 없음」은 선글라스엔 사실이고 유료 상품엔 거짓이라 제품별로 막습니다.
**터치톡 뷰티기기는 의료기기·화장품 광고 규정이 따로 붙습니다.** 그 축은 그쪽이 채워 넣으셔야 합니다.

`products/touchtok.json` 을 틀만 만들어 뒀습니다. `_needsOwnerInput` 에 빈 칸을 적어뒀습니다.

## 2. 받고 싶은 것 — 터치톡 오픈마켓

메모리에 「11번가·G마켓·옥션은 터치톡 사업자 명의로 이미 입점」이라고만 있고 그 이상을 모릅니다.

| # | 묻는 것 |
|---|---|
| 1 | **터치톡 카페24 주소** (피엔엘에코 쪽은 `pdkent.cafe24.com`) |
| 2 | **11번가·G마켓·옥션** 각각 — 마켓플러스 연동인지, 각 셀러오피스에서 직접 올리는지 |
| 3 | **등록하다 걸린 함정** — 아래 제 것과 교환합니다 |
| 4 | **터치톡 제품 정본** — 품목·모델명·가격·인증번호, 인스타/틱톡 계정명 |
| 5 | **메타 광고계정** — 「자동화 사용」 제한이 지금 풀렸는지 |

### 제가 겪은 함정 (먼저 드립니다)
- **마켓플러스는 값이 두 벌입니다.** 일괄입력 레이어(숨김)와 실제 전송 필드
  `template_data[shopn|ncp_1njmfm_01][market_data][...]` 가 따로 놉니다. **보이는 것만 고치면 전송이 안 갑니다.**
- **`is_default_*` 체크박스를 켜야 내 값이 쓰입니다.** 요약설명 45자가 안 바뀌던 원인이 이것이었습니다.
- **마켓플러스 상세는 팝업**(`window.open` + 이름)입니다. 차단되면 `window.open=u=>{location.href=u}` 로 같은 탭 이동.
- **카페24 에디터**: textarea 교체 후 편집기 `저장`을 **먼저 누르면 옛 내용으로 되돌아갑니다.** 건너뛰고 바로 `상품수정`.
- **쿠팡**: 상세설명 편집기 `저장` → 그 다음 `수정 및 검수 요청`. 반대로 하면 이탈 경고.
- 쿠팡 상세 세로 3,000px 이하, GIF 불가. 네이버/카페24는 860px, 쿠팡은 780px.

### 왜 필요한가
**RayTok 선글라스를 11번가·G마켓·옥션에 올려야 하는데 사업자가 달라 그 계정으로 못 보냅니다.**
터치톡 카페24에 복제할지, 피엔엘에코로 신규 입점할지 판단해야 합니다. 2번·3번이 그 재료입니다.

공통 값은 이미 압니다: 출고지·반품지 **경기도 화성시 동탄순환대로 830 SK V1 센터 B151호 (18468)**, **롯데택배**.
