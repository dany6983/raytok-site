# 세션 간 정기 교신 규약 (2026-10-31 대표님 지시)

세션끼리 직접 메시지가 안 닿는다(각자 격리된 컨테이너). **레포가 우편함이다.**
**매시 정각(09~19시) 양쪽이 같은 절차를 돈다.**

## 파일 네 종류

| 파일 | 누가 쓰나 | 어떻게 |
|---|---|---|
| `STATUS-<나>.md` | 자기 것만 | **통째로 덮어쓴다.** 지금 상태만 담는다 |
| `inbox-<상대>.md` | 상대에게 할 말 | **맨 아래에 덧붙인다.** 남의 줄을 고치지 않는다 |
| `SKILLS.md` | 양쪽 | 새로 알아낸 함정·요령을 덧붙인다 |
| `to-*.md` | 양쪽 | 긴 편지. 자주 쓰지 않는다 |

**자기 파일만 덮어쓴다. 상대 파일은 맨 아래에 덧붙이기만 한다.** 이 규칙이 충돌을 막는다.

## 매시 절차

```bash
cd <raytok-site 클론>
git pull --rebase origin main
```

1. **`inbox-<나>.md` 를 읽는다.** 처리한 항목은 줄 머리에 `[x]` 를 붙인다. 지우지 않는다.
2. **`STATUS-<나>.md` 를 덮어쓴다.** 아래 틀을 그대로 쓴다.
3. 새로 알아낸 함정·요령이 있으면 **`SKILLS.md` 맨 아래에 덧붙인다.** 없으면 건너뛴다.
4. 상대에게 할 말이 있으면 **`inbox-<상대>.md` 맨 아래에 덧붙인다.** 없으면 건너뛴다.
5. 커밋·push.

```bash
git add marketing/handoff
git commit -m "sync: <HH>시 상태"
git push origin main || (git pull --rebase origin main && git push origin main)
```

**바뀐 게 없으면 커밋하지 않는다.** 빈 커밋은 노이즈다.

## STATUS 틀

```markdown
# STATUS — <세션 이름>
갱신: 2026-MM-DD HH:MM

## 지금 하는 것
- 

## 끝낸 것 (지난 한 시간)
- 

## 막힌 것 / 대표님 결정이 필요한 것
- 

## 상대에게 영향 가는 것
- 
```

「막힌 것」은 **중요하다.** 상대가 이미 푼 문제일 수 있다.

## 지키는 선
- 키·토큰·비밀번호·API 키는 적지 않는다
- 개인 휴대폰·개인 이메일은 적지 않는다
- **모르는 건 「모름」이라고 적는다. 추측으로 채우지 않는다**
- 상대 담당 영역을 손대기 전에 inbox 로 먼저 알린다
- 상대 세션의 권한으로 내가 막힌 일을 대신 시키지 않는다
