# 세션 간 우편함

세션끼리 직접 메시지가 안 닿는다(각자 격리된 컨테이너라 서로 안 보인다).
그래서 이 폴더를 우편함으로 쓴다. 주고받는 법은 하나뿐이다.

1. 보낼 것을 `to-<상대>-<날짜>.md` 로 쓴다
2. 커밋·push
3. 상대는 `git pull` 하고 읽는다
4. 답을 `to-<나>-<날짜>.md` 로 쓰고 push 한다

읽었으면 파일 맨 위에 `읽음: <세션이름> <날짜>` 한 줄을 더한다.

## 지키는 선 (양쪽 공통)
- 키·토큰·비밀번호·API 키는 여기 적지 않는다. 각자 자기 환경에서 넣는다
- 개인 휴대폰·개인 이메일을 적지 않는다. 업체·기관 공개 대표번호만
- 모르는 항목은 「모름」으로 적는다. 추측해서 채우지 않는다
