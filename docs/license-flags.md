# RayTok 라이선스 flags (1바이트)

| 비트 | 값 | 이름 | 뜻 |
|---|---|---|---|
| 0 | 0x01 | guide | 가이드/강사 호스트 기능 (1:N 방송·QR·기록) |
| 1 | 0x02 | ent | 기업(안전교육) 기능: 명단·기록 내보내기·꾸러미 |
| 2 | 0x04 | no_cloud | 클라우드 기능 전부 끔: 요약·온라인 번역·음성 생성. 사용자 동의보다 상위 |
| 3~7 | — | 예약 | 0 |

제품 변형: RayTok(소비자)=0x00 / RayTok Guide=0x01 / RayTok Edu=0x03 (필요 시 +0x04)

토큰 자리: 80B 중 flags 1B (kid1+iss4+exp4+flags1+cust6+sig64). 변경은 재발급.

앱 동작: no_cloud면 설정에 "회사 정책으로 클라우드 기능 꺼짐" 표시, 요약 체크박스 숨김, translate 엔진 강제 device.

# HTTP 429 rate_limited 응답 규격 및 앱(A) 사용자 안내 문구

릴레이는 한도 초과 시 `scope` 필드로 원인을 구분하여 반환합니다.

| 엔드포인트 | scope | 원인 | 앱(A) 사용자 안내 문구 |
|---|---|---|---|
| `/license/issue` | `ip` | 공인 IP당 하루 20회 초과 | "같은 네트워크(와이파이)에서 개통 요청이 많았습니다. 잠시 후 다시 시도해 주세요." |
| `/license/issue` | `device` | 동일 기기당 하루 5회 초과 | "해당 기기의 오늘 무료 발급 횟수(5회)를 초과했습니다. 내일 다시 시도해 주세요." |
| `/translate` | `ip` | 공인 IP당 분당 200회 초과 | "같은 네트워크에서 요청이 집중되었습니다. 잠시 후 다시 시도해 주세요." |
| `/translate` | `sub` | 단일 토큰당 분당 60회 초과 | "요청 속도가 너무 빠릅니다. 잠시 후 다시 시도해 주세요." |
