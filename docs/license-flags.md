# RayTok 라이선스 flags (1바이트)

| 비트 | 값 | 이름 | 뜻 |
|---|---|---|---|
| 0 | 0x01 | host | 가이드/강사 호스트 기능 (1:N 방송·QR·기록) |
| 1 | 0x02 | private | 개인(손님/카메라) 기능: 1:1 대화·카메라 번역 |
| 2 | 0x04 | meet | 회의 모드 기능 |
| 3 | 0x08 | desk | Desk(데스크톱) 회의·기록 기능 |
| 4 | 0x10 | bundle | **인터넷 번역 패키지** — `/translate` 는 이 비트 없으면 **403**(`why=no_package`). 무료 한도 없음. 호스트 코드(0x01)에 자동 포함 없음, **별도 구매**. 글자 세기(`TRANSLATE_CAP_CHARS`)는 패키지 안에서만. Desk(0x04\|0x08)는 시간 묶음 상품이라 `/translate` 를 지금처럼 쓴다. (B-3 정정판, 대표님 10-14 08:39·08:41) |
| 5~7 | — | 예약 | 0 |

제품 변형: 관광 1일/7일권 = 0x01 / 손님/카메라 = 0x02 / Desk = 0x08 / 인터넷 번역 패키지 = 0x10 (따로 산다 — 0x01 과 합쳐 0x11)

토큰 자리: 80B 중 flags 1B (kid1+iss4+exp4+flags1+cust6+sig64). 변경은 재발급.

앱 동작: no_cloud면 설정에 "회사 정책으로 클라우드 기능 꺼짐" 표시, 요약 체크박스 숨김, translate 엔진 강제 device.

# HTTP 429 rate_limited 응답 규격 및 앱(A) 사용자 안내 문구

릴레이는 한도 초과 시 `scope` 필드로 원인을 구분하여 반환합니다.

| 엔드포인트 | scope | 원인 | 앱(A) 사용자 안내 문구 |
|---|---|---|---|
| `/license/issue` | `ip` | 공인 IP당 하루 20회 초과 | "같은 네트워크에서 개통 요청이 많았습니다. 잠시 후 다시 시도해 주세요." |
| `/license/issue` | `device` | 동일 기기당 하루 5회 초과 | "해당 기기의 오늘 무료 발급 횟수(5회)를 초과했습니다. 내일 다시 시도해 주세요." |
| `/translate` | `ip` | 공인 IP당 분당 200회 초과 | "같은 네트워크에서 요청이 집중되었습니다. 잠시 후 다시 시도해 주세요." |
| `/translate` | `sub` | 단일 토큰당 분당 60회 초과 | "요청 속도가 너무 빠릅니다. 잠시 후 다시 시도해 주세요." |

> **참고 (공인 IP 공유 환경 제약과 2차 B2B 해결책)**:
> 여행사·학교·기업 등 NAT 뒤에서 공인 IP를 공유하는 환경에서는 단체 개통 시 21번째 기기부터 차단(`scope=ip`)될 수 있습니다.
> 이에 대한 근본적 해결책(B2B 코드 `limit_code` 분기 및 승격 한도)은 `docs/b2b-limits.md`에 설계되어 있으며, B2B 라이선스 체계가 도입되는 **2차(가이드 모드 정식 릴리스)**에서 구현 및 적용됩니다.
