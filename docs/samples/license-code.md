# 이용권 코드 — 정본 (2026-10-08, MASTER 11 · 마스터 01:10 ④)

**이 파일이 원본이다.** 앱(`src/license.js`)과 발급 도구(B, `relay/tools/mint-code.mjs` — 아직

## 1. 코드 모양

```
80바이트 = payload 16 + Ed25519 서명 64   →   Crockford base32 128자 (패딩 없음)
```

| 자리 | 무엇 | 비고 |
|---|---|---|
| `[0]` | 키 번호 | 공개키를 고른다 → **키를 갈 수 있다**. **0 = 시험 키**, 운영은 **1부터** |
| `[1..2]` | 예비 | 0 으로 둔다. 쓰기 전에 이 표를 고친다 |
| `[3..4]` | **기간(일)** | uint16 **일**, 빅엔디안. `0` = 기간 없음(§4-1). 1일권 = `1` · 7일권 = `7` |
| `[5..8]` | 만료 | uint32 **초**, 빅엔디안 (2106년까지). 기간이 있으면 **묵힘 한도**다(§4-1) |
| `[9]` | 플래그 | 아래 표 |
| `[10..15]` | 고객 | 6바이트 ASCII, 남으면 0 |

서명은 **payload 16바이트 그대로** 덮는다(해시 먼저 하지 않는다).

### 플래그 (마스터 01:10 ②, Play 점검표 10-03 · 결제_설계 §0)

| 비트 | 무엇 | 앱이 읽나 |
|---|---|---|
| `0x01` | **1:N 호스트 시작** — 가이드·현장교육·관광 (셋이 한 상품이다) | 읽는다 |
| `0x02` | 카메라·앱 개인 기능 (박스 코드) | 읽는다 |
| `0x04` | Meet | 아니오 (다른 제품) |
| `0x08` | Desk | 아니오 (다른 제품) |
| `0x10` | **서버 번역 묶음** — 폰에 모델이 없는 25개 언어 (대표님 10-13 19:10) | 읽는다 |

### 글자 표 (Crockford)

`0123456789ABCDEFGHJKMNPQRSTVWXYZ` — **I·L·O·U 가 없다.**
받을 때 `I`·`L`→`1`, `O`→`0` 으로 고쳐 받고, 하이픈·빈칸은 버리고 대소문자를 가리지 않는다.
`U` 는 **받지 않는다**(`base32` 거절). 보여 줄 때는 4자씩 끊는다(`groupCode`).

## 4-1. 기간(일) — **첫 등록 때부터 센다** (대표님 10-13 08:22, MASTER 11 §3-2)

> *"시작점은 가이드한테 QR코드 찍은 날부터 시작이 아니야?"*

관광객은 코드를 사지 않는다. 가이드/여행사가 미리 사 두고, 관광객이 **찍는 순간** 흐르기
시작한다. 그래서 코드에 박힌 절대 만료 하나로는 모자란다 — 팔린 날과 쓰이는 날이 다르다.

| 필드 | 뜻 |
|---|---|
| `[3..4]` 기간(일) | 첫 등록 뒤 **며칠** 쓰나. `0` 이면 기간 제한 없음 — 전과 같이 `[5..8]` 만 본다 |
| `[5..8]` 만료 | 기간이 있으면 **묵힘 한도**(발급 → 첫 찍기, 기본 90일). 안 찍은 코드는 흐르지 않는다 |

```
쓸 수 있는 끝 = 기간 0 이면            exp
                기간 있고 등록 전이면   exp               (아직 안 흐른다)
                기간 있고 등록 뒤면     min(exp, 등록시각 + 기간일)
```

**등록시각**(`activatedAt`)은 온라인 등록(`POST /license/redeem`)이 돌려주는 서버 값이다.
인터넷이 없는 자리에서 처음 쓰면 폰이 `max(now, lastSeenTime)` 으로 **임시**로 적고, 인터넷이
닿는 첫 순간 서버 값으로 **덮는다** — 폰 시계를 돌려 기간을 늘리지 못한다(§4 와 같은 규칙).
셈하는 자리는 앱에서 **하나**다: `src/license.js` 의 `effectiveExp` (D-193).

## 4. 만료를 재는 법 — 시계를 되돌려도 안 풀린다

```
만료 = max(Date.now(), lastSeenTime) / 1000 > exp
```

`lastSeenTime` = **본 적 있는 가장 큰 시각** (`Date.now()` · 서버 응답 `Date` 헤더 · 파일 시각
중 최대). D-129 체험 판정과 **같은 규칙·같은 자리**이고, 적는 곳은 `savePrefs` 한 곳이다(D-19).
→ 유예일은 두지 않는다. 시계 어긋남은 이 값이 막는다 (마스터 01:10 ③).

**만료 7일 전부터 설정 화면에 한 줄**을 띄운다 — 막지는 않는다(`license_soon days=`).
**돌고 있는 세션은 끊지 않는다.** 검사는 시작할 때 한 번이다.
