# 설계 — 웹 강연 ▶ 재생 · ■ 멈춤 · 휴식이 **손님 폰 소리**까지 다스린다 (10-26 마스터)

## 왜 (대표님 실기 10-26 19:02)
- ■ 멈춤을 눌러도 손님 폰은 **계속 읽는다**. 휴식도 띠만 뜨고 계속 읽는다.
- 멈춤 → ▶ 를 누르면 **문단 처음으로 돌아가 다시 읽기 시작**한다. 반복.

## 원인 (코드 되읽기, 짐작 아님)
1. 강사 `playStop()` · `setBreak(true)` 는 **강사 폰의 타이머만** 끈다. 손님에게 가는 전선 메시지가 없다
   (`break` 는 가지만 손님 `setBreakBand` 는 띠만 켠다 — `speechSynthesis` 를 건드리지 않는다).
2. 강사 `playStart()` 는 `goTo(resumePara)` → `sendScript(para)` 로 **같은 문단을 다시 보낸다**.
   손님은 그것을 **새 줄**로 받아 `speak()` → `speechSynthesis.cancel()` 뒤 **문단 처음부터** 읽는다.
3. 강사가 다음 문단으로 넘기는 시간은 글자 수(`paraMs`)인데 손님 폰 TTS 는 그보다 느리다 →
   문단마다 앞 문단이 **중간에 잘린다**. (멈춤·재생과 별개지만 같은 자리의 문제)

## 설계 (하나씩, 스위치 기본 켬 §3)
### A. 전선 메시지 둘 추가 — 글자 없음(P-14 무관)
- `{kind:'pause'}` : 강사 ■ 멈춤 · 휴식 켬 · 🎤 끼어들기 때 보낸다.
- `{kind:'resume'}` : 멈춘 **같은 문단**에서 ▶ 를 누를 때 보낸다. **문단을 다시 보내지 않는다.**
  `playStart()`: `resumePara === live.cur && live.state[cur]==='read'` 이면 `sendScript` 대신 `resume`.
  이전·다음·건너뜀으로 **자리를 옮기면** 그때만 `sendScript`(지금처럼). 그때 `play.pausedAt = 0`(NOW 4-1).
### B. 손님 폰 — 문장 단위로 읽고 자리를 기억한다
- 원고 문단은 **문장 배열**로 나눠 한 문장에 한 `SpeechSynthesisUtterance`, `onend` 에서 다음 문장.
  (안드로이드 크롬 `speechSynthesis.pause()` 는 믿을 수 없다 — 10-20 실기 `515bfd8` 과 같은 이유로 `cancel` 을 쓴다.)
- `pause` 받으면: `cancel()` 하고 `{para, sentIdx}` 를 적어 둔다. 띠(휴식이면 「쉬는 시간」) 켠다.
- `resume` 받으면: 적어 둔 `sentIdx` 부터 **이어 읽는다**. 새 `script` 줄이 오면 적어 둔 것은 버린다.
- 들은 줄(`tr`, 강사가 말한 것)은 지금과 같다 — 이 설계는 **원고 줄**만 바꾼다.
### C. 넘기는 시간 (따로 스위치)
- 손님이 문단 다 읽으면 `{kind:'para_done', para}` 를 보낸다(글자 없음). 강사는 `paraMs` 와
  **첫 para_done 중 늦은 쪽**이 아니라 — 손님 수가 여럿이니 — `paraMs × 1.5` 를 상한으로 두고
  그 안에 para_done 이 절반 이상 오면 넘긴다. (C 는 A·B 뒤에, 실기 한 번 보고.)

## 시험 (D-09 — 되돌리면 붉어야 한다)
- 손님 페이지에 `speechSynthesis` 가짜를 꽂아 `speak(text)`·`cancel()` 호출을 **센다**.
  1. ▶ → 손님 speak 1회(문단1 첫 문장). ■ → cancel 1회, 그 뒤 speak 0회(1초 기다려도).
  2. 같은 자리 ▶ → **문단 재전송 0건**(wsSend 가로채기), 손님 speak 는 **멈춘 문장부터**(첫 문장 아님).
  3. 휴식 → cancel 1회·speak 0회·띠 켬. 휴식 끝 → 이어 읽기.
  4. ■ → ◀ 이전 → ▶ : 2문단 전송 1건, 손님은 2문단 첫 문장부터.
- 마스터 행동 시험(`scratch behave`)은 강사 상태만 쟀다 — 손님 소리를 안 쟀다. **그래서 「된다」로 잘못 봤다**(MISTAKES #12).
