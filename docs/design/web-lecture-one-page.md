## 0. 한 줄
**강사는 말하거나 원고를 넘긴다. 손님은 QR 로 들어와 자기 언어만 고르고, 자기 언어로 듣고 본다. 질문은 말로 하고, 모두가 각자 언어로 듣고, 강사가 말로 답한다.**

## 1. 강사 화면

| 순서 | 화면 | 메모 |
|---|---|---|
| ① 이용권 | 코드 넣기 | 지금 그대로 |
| ② 준비 | **내가 말하는 언어 하나**만 고른다 · (선택) 원고 올리기(TXT·DOCX·HWPX) | ⟳ 번역 대상 언어 고르기 **없음** — 손님이 고른다 |
| ③ 시작 | QR + 6자리 코드 · 들어온 손님 수(언어별) | 원고가 있으면 첫 문단 대기 |
| ④ 진행 | 단추 셋: **◀ 이전 · ▶/■ 재생/멈춤 · 다음 ▶** · 🎤 끼어들기 | 재생 = 원고 자동 넘김(글자 수 속도, **기본 1.0배**, 0.8~1.5배). 🎤 = 원고 멈추고 실시간 말하기 → **🎤 를 한 번 더 누르거나 ▶ 재생을 누르면 멈춘 문단에서 다시 시작** |
| ⑤ 질문 | 질문 대기줄(이름·언어·순서) · 「받기 / 나중에」 | 받으면 질문이 강사 화면 + 강사 이어폰(강사 언어로) |
| ⑥ 끝 | 리포트(원문 + 각 언어) · 저장 · 공유 | |

## 2. 손님 화면

| 순서 | 화면 | 메모 |
|---|---|---|
| ① 들어오기 | QR 찍기 → 브라우저 열림 (안드로이드에 앱 있으면 앱) | 설치 없음 |
| ② 내 언어 | 언어 하나 고르기 · **바로 옆에 「언어팩 받기」 단추**(그 언어 팩이 없을 때만 보임) | 앱 = 그 자리에서 팩 받기 · 웹 = 브라우저엔 팩을 넣을 수 없으니(사실) **「앱 같이 받기」**(앱 + 그 언어 팩) — 안 받아도 서버 번역으로 계속 듣는다 |
| ③ 듣기 | **내 언어 자막 + 내 언어 소리** | ⟳ **원문은 기본으로 안 보인다** — 「원문 보기」 **접힌 단추**(옵션)로만. 번역이 아직이면 「번역 중…」 — 줄은 잃지 않는다(R-15) |
| ④ 질문 | **✋ 질문** → 차례가 오면 **말로** 묻는다 | 아래 3장 |
| ⑤ 끝 | 저장(선택) | |

## 3. 질문 흐름 (설계_2 §16 그대로, 특허 선만 ⟳)

| 순서 | 무슨 일 | 특허 선 |
|---|---|---|
| 1 | 손님이 ✋ → 대기줄 → 강사가 「받기」 | |
| 2 | 손님이 **자기 폰에 말한다** → **손님 폰이 글자로 바꾼다**(앱 = 폰 안 인식 · 웹 = 브라우저 받아쓰기) | ⟳ **소리는 우리 서버로 가지 않는다**(P-04 · P-16 ③) |
| 3 | 그 **글자(원문 + 언어)** 가 강사 폰으로 → 강사 화면·이어폰에 강사 언어로 | ⟳ 강사 폰이 받아서 번역하는 것은 **받는 쪽 번역**이라 OK |
| 4 | 같은 질문 **원문**이 모든 손님에게 → **각자 자기 언어로** 보고 듣는다 | ⟳ 보내는 쪽이 번역해 보내지 않는다(P-14 · 장부 43) |
| 5 | 강사가 **말로 답한다** → 평소 강연 길 그대로 모두에게 | |

- 한 번에 한 명. 강사가 끝내기 누르면 다음 사람.
- 질문은 리포트에 「질문」으로 남는다.

## 4. 번역은 누가 하나 (장부 51)
- **손님 폰이 한다.** 앱 = 폰 안 언어팩(ML Kit → 레이팩) · 웹 = 손님 브라우저 번역 → 안 되면 **방(서버)이 번역해 그 언어 손님에게만**(보조 길).
- 강사 쪽(앱·웹)은 **원문만** 보낸다. 번역문을 보내지 않는다.
- ⟳ 옛 설계_3 §3 "웹 청취자 번역은 가이드 폰 몫"은 **폐기**(특허 판정 10-20).

## 5. 이미 있는 것 / 고칠 것 (10-21 실기 기준)

| | 지금 | 고칠 것 |
|---|---|---|
| 강사 언어 고르기 | 번역 대상 여러 개 | 말하는 언어 하나만 |
| 강사 단추 | 「다음」만(시작 단추 없음) | 이전 · 재생/멈춤 · 다음 · 🎤 |
| 손님 원문 | 원문 + 번역 | 번역만 + 「원문 보기」 접힌 단추, 없으면 「번역 중」 |
| 손님 언어팩 | 없음 | 언어 고르기 옆 「언어팩 받기」(앱) / 「앱 같이 받기」(웹) |
| 끼어들기 재개 | — | 🎤 두 번 또는 ▶ → 멈춘 문단부터 |
| 질문 | 문자만 | 말로(손님 폰이 글자로) → 3장 |
| 번역 | 실기에서 안 보임 · 크롬 번역 메뉴 안 뜸 | 웹 B 0 (서버 번역 기본, 운영 재현) |
| 반복 | "한 번 이상 잘 안 됨" | 재현 → 원인 → 시험 |
