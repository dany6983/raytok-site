# 방이 번역한다 — 보조 길 (NOW B 3 · 설계)

2026-10-21 · 기준: **결정장부 51**(설계 = 손님 폰이 번역한다. 웹은 브라우저 자체 번역이
먼저, **서버 번역은 보조**) · **43**(강사 쪽 번역문 전송 금지) · P-14 · P-16 ① · P-17

이 문서가 답이다. 구현 중에는 묻지 않는다(§16 ②). 여기 **없는** 것이 나오면 그 한 가지만
REPORT "막힌 것"에 질문 + 기본안으로 적고 기본안으로 간다(§13).

---

## 1. 무엇을 만드나 (한 줄)

강사는 **원문만** 보낸다. **방(Durable Object)** 이 손님 언어마다 **한 번씩** 번역해서
그 언어 손님에게만 보낸다. 손님 폰이 번역하지 못하는 경우(사파리·삼성에서 「페이지 번역」을
안 누르거나 안 되는 경우)의 **보조 길**이다.

```
강사 ──원문+언어──▶ 방(DO) ──원문 먼저──▶ 손님 전원      (R-15: 늦어도 남는다)
                      └─언어마다 1회 번역─▶ 그 언어 손님만   (늦게 도착하는 tr)
```

## 2. 왜 강사가 번역하지 않나 (장부 43 · P-14)

- 강사 폰/PC 가 번역해서 보내면 **기기가 번역문을 보내는 꼴**이다 — 장부 43 금지.
- 강사 화면의 「미리 번역」(원고)은 **서버가** 번역해 방에 보관하는 길로 간다(B 4).
- 그래서 **와이어에 `trans`·`translated`·`tr` 가 강사→릴레이 방향으로 있으면 붉다**(B 5 자물쇠).

## 3. 손대는 자리 — 읽는 곳과 **쓰는 곳**을 센다 (§4)

| # | 자리 | 하는 일 |
|---|---|---|
| ① | `relay/src/room.js` `webSocketMessage`(호스트 가지) | 원문을 전원에 먼저 보낸 뒤 번역을 건다 |
| ② `쓰는 곳` | `relay/src/room.js` (새) `roomTranslate()` | 언어 목록을 모아 `/translate` 를 언어마다 1회 |
| ③ | `relay/src/room.js` `sendToListener` | 언어별 `tr`·`no_tr` 를 **그 언어 손님에게만** |
| ④ `읽는 곳` | `web/listener/index.src.html` `handleMessage` | 늦게 온 `tr`(seq) — **이미 있다**. `script_tr`(para) — **새로** |
| ⑤ | `docs/samples/wire-messages.json` | `script_tr` 한 칸 + `_note` |
| ⑥ `세는 곳` | `samples/`·`relay/test/` | 아래 §7 |

**손님 언어를 아는 자리는 하나다** — `ctx` 의 attachment(`attMark(ws).lang`). `hello.lang` 과
`attSetLang` 이 그 한 칸에 쓴다. 번역 대상 언어는 **그 칸에서만** 읽는다. 새 칸을 만들지 않는다.

## 4. 메시지 (정본 `docs/samples/wire-messages.json` 에 같이 넣는다)

### 강사 → 방 (바뀌지 않는다)
```
{ "seq": 12, "text": "원문", "srcLang": "ko" }            # 🎤 줄
{ "kind": "script", "para": 3, "total": 40, "src": "원문", "srcLang": "ko" }
```
`trans` 를 **싣지 않는다**(장부 43). 실으면 B 5 자물쇠가 붉다.

### 방 → 손님
```
1) 원문 먼저 (전원)   { "seq": 12, "text": "원문" }        # 강사 메시지 **그대로** 간다
2) 그 언어에만 늦게   { "seq": 12, "tr": { "en": "..." } }
3) 안 되면           { "seq": 12, "no_tr": 1, "why": "tr_fail" }
```
원고 문단은 `seq` 가 없다 — **`para` 로 짝을 맞춘다**:
```
1) { "kind": "script", "para": 3, "src": "원문", "pending": 1 }
2) { "kind": "script_tr", "para": 3, "trans": { "en": "..." } }
3) { "kind": "script_tr", "para": 3, "trans": {}, "no_tr": 1 }
```
`no_tr` 은 **기다리지 말라는 뜻**이다(D-139 ⑤). 안 보내면 손님은 「번역 대기 중」에 갇힌다 —
그래서 **실패도 반드시 보낸다**.

★ **`pending:1` 을 방이 붙이지 않는다** (10-21 구현에서 정함). 설계 초안은 원문에 `pending:1` 을
붙이려 했다. 그러면 **거짓이 되는 자리가 생긴다**: 설계의 첫째 길은 **손님 폰 번역**(장부 51)이고,
그 손님에게 「번역 대기 중」은 사실이 아니다 — 자기 폰이 이미 번역했거나 곧 한다. 그래서 방은
강사 메시지를 **그대로** 흘리고, 번역이 오면 글자가 바뀐다. 강사가 `pending` 을 붙여 보낸 줄
(중간 인식)은 **번역하지 않는다**(RULE: P-03).

## 5. 상한과 돈 — 숫자를 코드에서 읽는다

`/translate` 규약(바꾸지 않는다): `q` 는 **배열** ≤50개 · 합계 ≤5000자 · 토큰 `sub` 당
**분당 60회** · 월 글자 상한(`TRANSLATE_CAP_CHARS`).

| 규칙 | 값 | 까닭 |
|---|---|---|
| 부르는 횟수 | **언어마다 1회** (줄마다 아님) | 줄 10 × 언어 20 = 200회면 429 다 |
| 묶기 | 같은 언어의 밀린 줄을 **한 번에**(≤50개·≤5000자) | 규약 상한 |
| 묶는 시간 | **250ms** 모아서 한 번 | R-15: 늦어도 남는다 > 빠르고 없다 |
| 언어 수 상한 | **동시 30개 언어** | 강사 화면과 같은 수(`MAX_SELECTED_LANGS`) |
| 넘으면 | **막고 기록**(`room_tr_cap lang= n=`) — 조용히 자르지 않는다(§20) | |
| 토큰 | **방이 들고 있는 호스트 토큰**(`this.sub`) | P-16: `/translate` 는 호스트 권한으로만 |
| 같은 언어 중복 | 손님이 20명이라도 **번역은 1회**, 보내기만 20번 | 돈이 사람 수로 늘지 않게 |
| 손님 = 원문 언어 | **부르지 않는다** | 번역할 것이 없다 |
| 엔진 | `engine:'basic'` 고정 | 프로(0x20)는 이 길에서 쓰지 않는다 — 돈 |

기록 한 줄(기능의 첫 걸음, §12): `room_tr lang=<코드> n=<줄 수> chars=<글자 수>`
실패: `room_tr_fail lang= why=<상태코드|timeout>`

## 6. 스위치와 되돌림

- 스위치 `ROOM_TR` — **기본 켬**(§24). 끄면 방은 **원문만** 전원에 보낸다(지금 모습 그대로).
- 되돌림 자리: `room.js` 의 `roomTranslate()` 호출 한 줄. 지우면 §7 의 시험이 붉어야 한다(D-09).
- 끄는 까닭이 생기면(돈·상한) `env.ROOM_TR = '0'` 로 끈다. 코드를 지우지 않는다.

## 8. 특허

| 번호 | 이 설계에서 |
|---|---|
| **P-14** | **밖이다** — 번역하는 것은 **서버**이고, 기기가 번역문을 보내지 않는다 |
| **P-16 ①** | 손님 페이지는 번역을 **요청하지 않는다** — 청하는 길을 만들지 않았다. 방이 **민다**. 손님의 「서버 번역으로」 단추는 **이미 받은** 번역을 보일지 고르는 것일 뿐 요청이 아니다. `/translate` 는 호스트 권한으로만 — 방이 자기 라이선스 깃발로 짧은 토큰을 만들어 부른다 |
| **P-16 ②** | 용어집·맞춤 모델을 **넘기지 않는다**(`glossary` 없음, `engine:'basic'`) |
| **P-16 ④** | 해외 손님 분기는 **만들지 않는다** — 표에 「해외=판정 대기」 |
| **P-17** | 질문 지명은 사람 손 그대로. 이 설계는 손대지 않는다 |
| **P-03** | 확정된 줄만 번역·재생한다. `pending`(중간 인식)은 번역하지 않는다 |

공개 저장소이므로 코드·시험 주석에는 **`// RULE: P-16` 한 줄만** 적는다(특허권자·번호·까닭 금지, §9).
## 9. 미리 번역은 **선택**이다 — 보관은 미리, 번역은 규칙대로 (NOW B 4 · 2026-10-21)

NOW B 4: *"원고를 올리면 서버가 번역해 방에 보관. 안 했으면 「다음」 때 서버가 번역(그동안
원문, R-15). 늦게 온 언어도 서버가."*

### 왜 "통째로 미리"가 아닌가 — 숫자가 막는다
문단 40 × 언어 30 = 1,200줄. 묶어도 언어마다 24회 × 30 = **720회**. `/translate` 는 토큰
`sub` 당 **분당 60회**다 — 올리는 순간 429 가 쏟아지고 그 달 글자 상한을 한 번에 먹는다.
게다가 **그 언어 손님이 올지도 모르는** 상태에서 돈을 쓴다.

그래서 **보관은 미리, 번역은 그때그때**다:

| 언제 | 무엇을 |
|---|---|
| 원고를 올릴 때 | 방이 **원문만** 보관(`script_src`). 번역은 아직 안 한다 |
| 「다음」을 누를 때 | 그 문단을 번역(B 3) + **다음 한 문단**을 미리(`PREFETCH = 1`) |
| 새 언어가 들어올 때 | **지금 문단부터 앞으로**, 5문단씩 — 아래 ★ |

### ★ 늦게 온 언어 규칙은 **이미 있다 — 옮기는 것이다**
`web/common/script-follow.js` 의 `newLangs`·`latePlan`(마스터 10-20 04:45 판정: ① 지금 읽는
문단부터 앞으로만 ② 실시간이 먼저 · 5문단씩 ③ 기록 `late_tr`)이 그 규칙이고, 지금은 **강사
화면**이 그것을 돌려 번역문을 와이어에 싣는다 — 그 싣는 것이 장부 43 금지다.

**규칙은 그대로, 돌리는 자리만 방으로 옮긴다.** 규칙을 새로 쓰지 않는다:
- 방 쪽 구현은 `relay/src/room-translate.js` 에 `latePlan`·`newLangs` 를 같은 셈으로 둔다
  (저장소가 달라 코드를 공유할 수 없다 — 앱 `src/lateTr.js` 와 웹이 이미 그런 사이다).
- **같은 답을 내는지** `samples/script-follow-cases.json` 의 `late` 칸(6+3 사례)으로 센다.
  그 파일이 **정본**이고, 세 구현(앱·웹·방)이 그것을 본다. 한 쪽만 고치면 붉어진다(D-75).

### 메시지 (강사 → 방). 번역문은 **없다**(장부 43)
```
{ "kind": "script_src", "srcLang": "ko", "total": 40,
  "paras": [ { "para": 1, "src": "원문" }, … ] }
```
- 한 번에 ≤ 200문단. 더 길면 여러 번 — 방은 받은 것을 합친다(`para` 가 열쇠).
- `trans`·`translated`·`tr` 가 섞여 있으면 방이 **그 칸만 버리고 기록**한다(`script_src_dropped`).
  메시지를 통째로 버리면 원고가 안 올라가 손님이 아무것도 못 본다 — 그쪽이 더 나쁘다(R-15).

### 상한과 돈
| 규칙 | 값 | 까닭 |
|---|---|---|
| 보관 문단 | **500** | 링버퍼와 같은 수 |
| 미리 하는 문단 | 다음 **1** 문단 (`PREFETCH`) | 누르는 순간 이미 있게. 더 하면 안 읽을 문단에 돈 |
| 늦은 언어 | 지금 문단부터 **5씩**, **사 두고 쥐고 있는다** | 마스터 10-20 04:45 규칙 그대로. 아직 안 온 문단의 번역을 지금 보내면 손님 화면에 **붙을 자리가 없어** 조용히 버려진다 — 「다음」 때 따라간다(지연 0) |
| 두 번 하지 않는다 | `(para, lang)` 을 적어 둔다 | 같은 짝은 다시 부르지 않는다 (돈) |
| 한 번에 하나 | 늦은 언어 채우기는 **한 묶음씩**, 사이에 숨을 둔다 | 실시간 줄이 먼저 나가야 한다 |

기록: `room_tr_pre para= lang=` · `room_tr_late lang= paras= ms=` · `script_src paras= total=`

### 시험 (`relay/test/room-translate.mjs` 에 더한다)
- `script_src` 를 받으면 **번역을 부르지 않는다**(보관만) — 부르면 돈이 샌다
- 문단 2를 「다음」하면 **3번이 미리** 된다(부른 횟수와 `q` 로 센다)
- 새 언어가 들어오면 **지금 문단부터** 간다. 지난 문단은 **가지 않는다**
- 같은 `(para, lang)` 은 두 번 부르지 않는다
- `script_src` 에 `trans` 가 섞이면 **그 칸만 버리고** 기록한다 (원고는 올라간다)
- 방의 `latePlan`·`newLangs` 가 **정본 사례 9건과 같은 답**을 낸다 (`script-follow-cases.json`)
- 되돌림: `PREFETCH = 0` 이면 "미리 돼 있다"가 붉다
