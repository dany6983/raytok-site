# 읽는 법
- 「한글 같이」: 고치기 전 네 판 모두 24/24 줄이 번역 오기 전 한글을 보였다(🎤 줄 = broadcast → showSrcFor 가 원문). 실기에서 trorder=0 이 「번역문만」이던 것은
  trorder=0 이면 아이폰도 레이팩을 받아(레이팩 요청 2) 폰 안에서 바로 번역했기 때문 — 원인 = 11-10 ①(아이폰 → 처음부터 방 번역) + broadcast 원문 표시. 고침 = ③ srcHide.
- 「화면 죽음」: 이 컨테이너에서는 재현 못 함(힙 3.2~3.5MB 차이 없음). 2×2 에서 tts106 만 다른 것 = 배속 발화(7개 중 6, 1.2/1.4배)·합친 긴 발화.
  trorder=0(레이팩 실음)이어도 실기 4분 멀쩡 → 메모리 짐작보다 106 쪽. 아이폰만 106 끔(`?tts106=1` 로 다시 켬) — **짐작, 실기로 가름**.
