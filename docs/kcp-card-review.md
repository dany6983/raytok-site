# NHN KCP 카드사 심사 — 심사 중에 바꾸면 안 되는 것 (2026-10-19)

KCP 대외지원팀(카드사 심사담당) 회신을 **사실 그대로** 적는다.

## 사실

- 카드사 등록 심사가 시작됐다. 기간은 **영업일 기준 3~15일**.
- 심사 중 아래가 바뀌면 **심사불가**다.
  1. 사이트 하단 정보 변경 — 회신에 **"전화번호" 등**으로 적혀 있다
  2. 상품 구매 불가 처리(**품절**)
  3. 사이트 URL 주소 변경
- 결과 확인: **partner.kcp.co.kr → 상점정보관리 → 카드사심사 등록현황**
- 상태는 **미등록 → 심사중 → 완료** 순으로 바뀐다.
- **"완료"로 표기되는 카드사부터 결제가 된다.**

## 그래서 지금 할 수 없는 것

- **실결제 1건 시험**(B 30 의 마지막 확인)은 **완료된 카드사가 나올 때까지 못 한다.**
  릴레이 쪽 확인(`node scripts\prod-license-e2e.mjs` 8건)과 시험(`pay_v1_test` 21건 ·
  `pay_test` 117건)은 끝나 있다. 남은 것은 실제 카드 1건뿐이다.

## 동결과 무관한 것

- **릴레이(Cloudflare Worker) 배포**는 사이트 HTML·URL·하단 정보를 바꾸지 않는다.
  B 30 처럼 릴레이만 고치는 것은 심사와 무관하다.

## 자물쇠 (사람 기억에 걸지 않는다)

- 굳힌 값: `docs/kcp-review-freeze.json` — 하단 정보 줄 · 그 줄을 든 페이지 30개 ·
  URL 39개 · 상품 5개(살 수 있는 것 2개)
- 지키는 시험: `samples/kcp_freeze_test.js` (`npm test` 안, `npm run test:kcp-freeze`)
  - 하단 정보가 바뀌거나, 있던 URL 이 없어지거나, 살 수 있던 상품이 품절로 돌아가면 **붉어진다**
  - 새 페이지를 **더하는** 것은 막지 않는다 — KCP 가 말한 것은 **바뀌는** 것이다
- **심사가 "완료"된 뒤 푸는 법:** `docs/kcp-review-freeze.json` 의 `frozen` 을 `false` 로.
  값을 다시 뜨려면 `node samples/kcp_freeze_test.js --write`.

## 10-19 에 하마터면 어긴 것

회신의 "전화번호"를 **구매 폼의 휴대폰 칸**으로 잘못 읽고 그 칸을 선택으로 바꿨다.
바꾼 것은 **사이트 하단 정보**가 아니라 결제 폼이었지만, 심사 중 구매 흐름을 건드린 것이라
되돌렸다(커밋되지 않았다). 회신이 가리키는 것은 **사이트 하단의 사업자 정보 줄**이다.
