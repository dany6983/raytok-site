# RayTok 웹 강사 화면 — 설계 v0 (2026-10-07, 마스터)

목적: 교육 현장에서 강사가 **PC 브라우저**로 원고를 올려 문단을 넘기고, 청취자는 폰 청취 페이지(web/listener)로 자기 언어 번역을 받는다. 앱(원고 모드 §16)과 같은 흐름의 **웹판**. 음성 인식 없음(1차). 특허 조건: `RayTok-판정_착수조건_1006.md` §10 넷.

## 0. 한눈에
| | |
|---|---|
| 주소 | `raytok.kr/web/host/` (공개 저장소 raytok-site) |
| 누가 | 강사(호스트). **이용권 토큰 필수**(0x04 meet 또는 0x08 desk 플래그 — 교육 패키지는 0x04 로 발급) |
| 무엇 | 원고 올리기(TXT·PDF·DOCX) → 문단 나눔 → **미리 번역**(relay `/translate`) → 방 만들기(`/room`, QR) → 문단 넘김(`/ws`) → 끝나면 리포트 3×3 + 참석 명단 |
| 청취자 | 지금 청취 페이지 그대로. 받기만(P-16 ①) |
| 안 하는 것 | 음성 인식(1차) · 원고로 도메인 판정·모델 선택(P-17·플리토) · 해외 호스트 가입·결제(P-16 ④) · 자동 요약(Desk 만) |

## 1. 화면 넷
1. **들어가기**: 이용권 코드 입력 → relay `/license/verify` → 토큰 localStorage. 없으면 "이용권이 필요합니다 → raytok.kr/edu". 국가 확인은 토큰 발급 쪽(국내 한정) — 화면은 토큰만 본다.
2. **준비**: ① 파일 올리기(TXT·PDF·DOCX, 브라우저 안에서만 읽음 — L3) ② 문단 미리보기·손으로 합치기/나누기 ③ 청취 언어 고르기(여럿) ④ "미리 번역" — 문단 × 언어를 relay 로, 진행 막대, 결과는 **브라우저 IndexedDB**(서버 저장 0) ⑤ 명단 붙여넣기(선택, 8번 — 이름·언어). 
3. **진행**: 왼쪽 원고 문단 목록(현재 강조), 오른쪽 QR·참석 수(`att`)·언어별 인원. 단추: **다음 / 이전 / 건너뜀 / 쉬는 시간**. 키보드 → ← 스페이스. 넘기면 `/ws` 로 `{kind:"script", para, src, trans:{lang:text}}` — **원문 + 미리 번역한 번역문**을 청취자 언어로 보낸다(청취자는 번역 안 함 ✔ P-16 ①; 기기 간이 아니라 서버 경유라 P-14 밖).
4. **끝**: 종료 요약(참석·시간·읽은 문단/건너뜀) → 리포트 저장 3×3(`web/common/report.js` 그대로) + 참석 CSV. 방 닫기 → relay 가 줄·참석 삭제(기존).

## 2. 와이어 (A 정본 `docs/samples/wire-messages.json` 에 마스터가 추가 요청)
- `script` 메시지: `{kind:"script", para:int, total:int, src:string, srcLang, trans:{[lang]:string}, at}` — 청취자 페이지는 `trans[myLang]` 없으면 `src` 표시(R-15).
- `skip`: `{kind:"skip", para}` · `break`: `{kind:"break", on:bool}`.
- 청취자 `hello` 에 `name`(선택) — 8번 명단 대조용. 서버는 저장 안 함(진행자 화면으로만).

## 3. 데이터·개인정보
- 원고·번역·명단 전부 **강사 브라우저**(IndexedDB). 서버는 번역 글자만 지나간다. 방 끝나면 relay 는 지운다. 처리방침 한 줄: "올린 원고는 번역을 위해 문장 단위로 번역 서비스에 전송되며 서버에 저장되지 않습니다."
- 미리 번역 비용: 문단 50 × 언어 3 × 200자 = 3만 자 ≈ 상한 안. `/usage` 에 집계(기존 글자 수 계산 그대로).

## 4. 순서 (B)
L2-fix(`trans` 토큰 통일) → **L4-1** 들어가기+준비(TXT 만) → **L3** PDF·DOCX 읽기 → **L4-2** 진행(ws script) + 청취 페이지 `script` 수신 → **L4-3** 끝(리포트·명단). 각 단계 되돌림 확인·외부 요청 0 시험. 청취 페이지 변경은 **기존 9절 시험 그대로 통과**.
