## 1. 목록 — 화면에 있는 것과 "누르면 무엇이 되어야 하나"

화면 코드(`web/listener/index.src.html`)에서 **세어서** 적었다. 쓰는 사람이 보는 차례대로다.

### 들어가기 화면 (`#join-screen`)

| 항목 | 무엇이 되어야 하나 |
|---|---|
| 언어 고르기 `#lang-select` | **목록이 차 있어야 한다.** 코드에 박힌 것은 `ko` 한 줄뿐이고 나머지는 `langs.json` 에서 채운다 — 안 채워지면 손님은 한국어밖에 못 고른다 |
| 이름 `#name-input` | 비워도 들어가진다(익명). 적으면 질문에 그 이름이 붙는다 |
| 방 번호 `#room-input` | 주소에 `?room=` 이 있으면 자동으로 찬다 |
| 들어가기 `#btn-join` | 누르면 **대화 화면(`#chat-screen`)으로 넘어가고** 릴레이에 붙는다 |

### 대화 화면 (`#chat-screen`)

| 항목 | 무엇이 되어야 하나 |
|---|---|
| 연결 상태 `#status-badge` | 붙는 중·붙음·끊김을 **글자와 점 색**으로 말한다 |
| 받은 줄 `#chat-list` | 강사가 말하면 **그 줄이 뜬다**. 이것이 안 되면 나머지는 의미가 없다 |
| 🔊 소리 켬/끔 `#btn-toggle-tts` | 누르면 글자가 바뀌고, **끄면 읽던 것·줄 선 것도 즉시 멈춘다**(마스터 14:57 고침) |
| 🗣 목소리 `#btn-open-voice-picker` | 창이 열리고 **목소리 목록이 찬다**. 닫기로 닫힌다 |
| 🔒 화면 꺼도 듣기 `#btn-bg-audio` | 누르면 켬/끔이 **눈에 보이게** 바뀐다 |
| 글자 크기 `#btn-font-s/m/l` | 셋이 **실제로 다른 크기**여야 한다 (셋 중 둘이 같으면 고장) |
| ✋ 질문 `#btn-ask` | **강사가 열기 전엔 숨어 있다**(`display:none`). 열리면 창에 글을 적어 보낸다 |
| ⬇ TXT `#btn-save` | 고르는 창이 열리고, 실행하면 **파일이 실제로 떨어진다** |
| ⛶ 전체화면 `#btn-fullscreen` | 전체화면으로 들어간다 |
| 음성 없음 띠 `#voice-notice` | 폰에 그 언어 음성이 없으면 뜨고, **깔는 방법까지 알려 줘야 한다** (대표님 "언어팩 까는 것도 없다") |
| 쉬는 시간 띠 `#break-band` | 강사가 켜면 뜨고 **끄면 사라진다** |
| 방 상태 `#room-state` | 읽어 주는 영역(`aria-live`) |
| 다시 붙기 | 끊기면 **저절로** 다시 붙고, 붙은 뒤 줄이 다시 들어온다 |
| 끝 화면 `#end-modal` | 강사가 끝내면 뜨고, **줄 수·시간이 차 있고**, 거기서도 저장할 수 있다 |

### 표가 말하는 것

**움직이는 것은 다 움직인다.** 손님 화면의 단추·띠·상태 **25가지**를 두 브라우저로 돌려
**안 되는 것이 없었다**(46 됨 / 0 안 됨). 대표님이 보신 "손님폰 기능이 하나도 안 돼" 는
**이 화면의 단추들이 죽은 것이 아니다** — 아래 「고칠 것」 과 「폰에서만 아는 것」 을 본다.

### ★ 고칠 것 하나 — 음성 없을 때 **깔는 방법을 안 알려 준다**

대표님 *"언어팩 까는 것도 없다"*. 문구를 직접 읽어 확인했다
(`web/listener/ui-strings.json` → `voice_absent_notice`):

> 이 언어는 음성이 없어 자막만 나옵니다

**무엇이 없는지만 말하고 어떻게 하라는 말이 없다.** 이것은 「모름」이 아니라 **안 됨**이다 —
띠가 뜨는지와 무관하게 **문구 자체에 안내가 없다**. 81개 언어 모두 그렇다.

### 폰에서만 아는 것 (「모름」 — 대표님 실기로 남긴다)

| 항목 | 왜 여기서 못 재나 |
|---|---|
| 음성 없는 언어에서 **띠가 실제로 뜨는가** | 머리 없는 브라우저의 음성 목록이 폰과 다르다. Chromium 은 판정이 `unknown`, WebKit 은 `ko:0 en:1` 로 **폰과 다른 답**을 준다 |
| 그 띠의 **안내 문구가 폰에서 읽히는가** | 위와 같다. 다만 **문구에 안내가 없다는 것은 위에서 이미 확정했다** |

이 둘 말고는 대표님이 확인하실 것이 없다.
