# 20문장 ⓑ basic — 아직 비어 있다 (틀)

**이 파일은 기계가 채운다. 손으로 적지 않는다.**
여기 실릴 것은 **ⓑ 칸(릴레이 basic)의 번역문뿐**이다. 점수는 대표님이 A·B·C 로 매기시고,
섞는 것은 마스터가 한다 — 그래서 이 표에는 **엔진 이름을 적지 않는다**(블라인드).

문장 표는 **앱 저장소 `src/eval20.js` 하나**가 정본이다(D-193). 이 저장소로 베끼지 않는다.

## 왜 비어 있나

운영 릴레이(`raytok-relay.raytok.workers.dev`)에 닿는 것은 **대표님 PC** 뿐이다.
이 세션의 컨테이너에서는 그 주소가 CONNECT 403 으로 막혀 있어 숫자를 만들 수 없다.
없는 숫자를 적는 것보다 **빈 칸이 낫다**(AGENTS §21 — 사실만).

## 채우는 두 길

**ⓐ 대표님 PC 에서 바로 파일까지** (저장소를 받아 두신 경우) — 한 줄:

```
RELAY_URL=https://raytok-relay.raytok.workers.dev \
EVAL20=../raytok-native1/src/eval20.js \
node scripts/eval20-basic.mjs --out
```

→ 이 파일(`docs/eval20-basic.md`)이 그 결과로 **덮어써진다.** 그 뒤 `git add docs/eval20-basic.md`.

**ⓑ 출력만 보내 주시는 경우** — 대표님은 `--out` 없이 돌리고(또는 화면을 긁어 보내시고),
받은 쪽에서 그 글을 파일로 저장한 뒤:

```
node scripts/eval20-basic.mjs --paste=<받은-출력.txt>  --out
cat <받은-출력.txt> | node scripts/eval20-basic.mjs --paste=- --out
```

`--paste` 길은 **망을 한 번도 부르지 않는다** — 표 줄만 되읽어 같은 모양으로 다시 쓴다.
사람이 손으로 옮겨 적는 자리를 없애려고 둔 것이다(옮겨 적으면 한 줄이 조용히 빠진다).
