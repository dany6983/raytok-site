## 돌리는 법

```bash
cd relay && npx wrangler dev --local --port 8787      # 창 1
python3 -m http.server 8099                           # 창 2 (저장소 뿌리)
RELAY_URL=http://127.0.0.1:8787 node scripts/host-token.mjs | grep -E '^ey' | tail -1 > /tmp/tok.txt
SITE=http://127.0.0.1:8099 E2E_RELAY=http://127.0.0.1:8787 TOK=$(cat /tmp/tok.txt) \
  SHOT_DIR=/tmp/shots node scripts/master-click.cjs
```

`ENGINE=webkit` 로 아이폰 쪽도 돌게 되어 있지만 **이 컨테이너에는 웹킷이 깔리지 않는다**
(내려받기가 망 정책에 막힌다). 아이폰은 대표님 실기로 가린다.
