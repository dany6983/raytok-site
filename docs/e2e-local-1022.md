# 진짜 릴레이로 끝까지 — 로컬 (2026-10-22) · 결정장부 46 · NOW B 5

가짜 방이 아니라 **릴레이 코드 자체**(`wrangler dev --local`)와 **진짜 화면**으로 돌린 표다.
10-21 판(`e2e-local-1021.md`)에 **질문 길**과 **자물쇠**를 보탰다.

## 결과 — 손님 셋이 각자 언어로, 질문까지

| 단계 | en | zh-CN | **ne** |
|---|---|---|---|
| 원고 문단 1 (「다음」) | `[en] 안전 교육을…` | `[zh-CN] …` | `[ne] …` |
| 🎤 줄 (원고 밖 말) | `[en] 오늘 점심은…` | `[zh-CN] …` | `[ne] …` |
| **손님 질문**(말로) | (질문한 손님) | `[zh-CN] Can we use this offline?` | `[ne] …` |

★ **`ne` 가 핵이다.** 강사 화면은 `ne` 를 **사전 번역하지 않았다.** 그런데 ne 손님이
자막을 자기 말로 받았다 — **방이 번역한 것**이다(B 3·B 4 · 결정장부 51).

★ **질문**: 손님이 ✋ → 강사가 사람 손으로 지명(P-17) → **손님 폰이 글자로** 바꿔 올리고
(소리 칸 없음 · RULE: P-04) → **다른 손님 전부**가 각자 말로 받았다 → 강사 화면은
`"[ko] Can we use this offline?" (원문: Can we use this offline?)` 로 보이고 읽어 준다.

## 자물쇠 — 전선에서 쟀다

```
[chromium] 9 자물쇠: 프레임 9 · 번역 칸 0
```

강사 화면이 **전선에 올린 프레임 9개** 어디에도 `trans`·`translated`·`tr` 가 없다
(깊이 전부 센다). 릴레이가 받은 뒤의 모양이 아니라 **보낸 것**을 재므로, 릴레이가 칸을
떨어뜨려도 못 속인다. 결정장부 43 · RULE: P-14.

## 돌리는 법

```bash
# ① 가짜 번역 상류 (로컬 릴레이에는 번역기가 없다 — 아래 「왜 필요한가」)
node scripts/e2e-fake-upstream.cjs 8099

# ② 릴레이 — relay/.dev.vars 에 (그 파일은 gitignore 다. 운영 비밀값을 쓰지 않는다)
#    LICENSE_SECRET=<아무 32바이트 hex>   LICENSE_SALT=<16바이트 hex>   ADMIN_SECRET=<아무 값>
#    GOOGLE_TRANSLATE_KEY=local-e2e
#    GOOGLE_TRANSLATE_URL=http://127.0.0.1:8099/translate
#    RELAY_BASE_URL=http://127.0.0.1:8787
#    ROOM_TR=1
cd relay && npx wrangler dev --local --port 8787

# ③ 사이트
python3 -m http.server 8080 --bind 127.0.0.1

# ④ 강사 이용권 → 끝까지
export E2E_DIR=/tmp/e2e && mkdir -p $E2E_DIR
RELAY_URL=http://127.0.0.1:8787 node scripts/host-token.mjs | grep -E '^eyJ' > $E2E_DIR/tok.txt
node scripts/e2e-local-relay.cjs
```

### 왜 가짜 상류가 필요한가
로컬 릴레이에는 번역기가 없다. `GOOGLE_TRANSLATE_KEY` 가 없으면 기본 길이 500 을 던지고,
`mock` 엔진은 **관리자만** 쓴다. 그러면 손님은 「번역 안 됨」만 받고 **번역을 잴 수 없다** —
10-22 첫 판이 그렇게 돌았고, 시험은 그 배지를 번역으로 읽어 **거짓 초록**이었다. 가짜 상류는
**구글 v2 규약을 그대로** 지킨다(배열이 아니면 400 · 답은 `{data:{translations:[…]}}`) —
가짜가 느슨하면 시험이 거짓말한다(D-11).

## 이 환경이 **재지 못한 것** — 실기 목록으로 (「모름」은 막힘이 아니다)

| 무엇 | 왜 못 쟀나 | 누가 본다 |
|---|---|---|
| **웹킷**(아이폰 사파리 엔진) | 이 컨테이너에 안 깔렸고 내려받기가 막혀 있다 | 대표님 실기 — 아이폰 사파리·아이폰 크롬 |
| **소리 읽기** | 이 기계에 TTS 음성이 **하나도 없다**(`have:"unknown"`) — 화면이 「음성 없음」이라 말하고 자막만 낸다. 맞는 동작이다 | 대표님 실기 — 폰 넷 |

시험은 이 둘을 **조용히 건너뛰지 않는다**: 웹킷은 「안 깔렸다」를 한 줄로 적고, 소리는
화면이 「음성 없음」이라 말하는지를 보고 그 까닭을 적는다(§20 · D-70 — 모름은 없음이 아니다).
