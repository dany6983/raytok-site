# B 백로그 — 출시까지 끝까지 (2026-10-10 08:15, 마스터)

**이 파일이 B 의 할 일 목록이다. 위에서 아래로 간다.**
MASTER.md 는 **그날그날의 판정·급한 끼어들기**이고, 이 파일은 **끝까지의 줄**이다.
충돌하면 **MASTER 가 이긴다**(마스터가 급한 것을 끼워 넣었다는 뜻이다).

## 어떻게 쓰나
1. 한 줄을 집으면 REPORT 맨 위에 `진행 중: <줄> — 시작 HH:MM` 적고 **민다**.
2. 끝나면 **커밋·푸시·REPORT** 하고 이 파일의 그 줄을 `[끝]` 으로 바꿔 같이 민다.
3. **마스터 판정을 기다리지 않는다.** 바로 다음 줄로 간다.
4. 설계에 없는 것이 나오면 그 **한 가지만** REPORT "막힌 것"에 **질문 + 기본안** 적고
   **기본안으로 진행**한다(50초 규칙).
5. **합격 조건을 다 채우지 못하면 `[끝]` 으로 적지 않는다.** 절반이면 `[절반]` 과 무엇이
   남았는지 적는다 — 10-10 에 줄 15 를 "완수"로 적었는데 본문이 없었다.

## 모든 줄에 걸리는 조건 (매번 확인)
