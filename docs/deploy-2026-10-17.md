| 화면에 나온 것 | 뜻 | 할 것 |
|---|---|---|
| `Required Worker name missing` | 폴더가 `relay` 가 아니다 | **Ctrl+C** → `cd C:\github\raytok-site\relay` → 다시 |

`git pull` 이 **`Your local changes ... would be overwritten`** 로 멈추면 그 PC 에서 고친 것이 있다는
뜻이다. 지우지 않고 **치워 둔다**:

```powershell
cd C:\github\raytok-site
git stash push -u -m "pc-local"   # 고친 것 + 추적 안 되는 파일까지 치운다 (없어지지 않는다)
git pull
```
나중에 꺼내려면 `git stash list` · `git stash pop`. 치운 내용만 보려면 `git stash show -p`.

## 2. 배포 전/후 확인

### ① 배포 전 — `wrangler secret list` 로 **이름만** 본다

| 이름 | 없으면 무엇이 멈추나 |
|---|---|
| `LICENSE_SECRET` | 토큰 서명. 이용권 전부 멈춤 |
| `LICENSE_SALT` | `/license/issue` 가 500 |
| `MINT_PRIVATE_KEY` | 쿠폰이 **시험 키(0)** 로 찍히고 정식 앱이 거부한다 (10-13 12:35 에 지우신 그것) |
| `PORTONE_API_SECRET` | `/pay/complete` 의 **V2** 확인 → 없으면 503 `pg_secret_missing` |
| `IMP_API_KEY` ★ | `/pay/complete` 의 **V1** 확인(지금 KCP 채널이 V1 이다) → 없으면 503 `pg_secret_missing` · `why=imp_secret_missing`. **이것이 없으면 실결제가 들어와도 쿠폰이 안 나온다** |
| `IMP_API_SECRET` ★ | 위와 같음 (둘 다 있어야 한다). 포트원 콘솔 → 결제 연동 → **식별코드·API Keys** 의 V1 API Secret |
| `PORTONE_WEBHOOK_SECRET` | `/pay/webhook` → 503 `pg_secret_missing` |
| `GOOGLE_TRANSLATE_KEY` | basic 번역 |
| `DEEPGRAM_API_KEY` | Desk 인식 |
| `LLM_API_KEY` | 프로 엔진이 **basic 으로 떨어진다**(멈추지는 않는다, 기록에 `no_key`) |
| `ADMIN_SECRET` | 관리 끝점 |

**있으면 안 되는 것 둘: `PORTONE_API_BASE` · `IMP_API_BASE`.** 있으면 결제 조회가 그 주소로
간다(시험용 자리). 목록에 보이면 지운다 — `npx wrangler secret delete PORTONE_API_BASE`
(또는 `vars` 에 있으면 `wrangler.toml` 에서 뺀다), `IMP_API_BASE` 도 같게.

조이개(선택, 없으면 기본값): `LLM_DAILY_CAP_USD`(5) · `LLM_TIMEOUT_MS`(2000) · `LLM_PROVIDER`(gemini) ·
`LLM_MODEL` · `TRANSLATE_CAP_CHARS` · `LICENSE_MAX_DEVICES`(1) · `DESK_KEEP_DAYS` · `DESK_HARD_CAP_MIN`.

### ② 배포 뒤 — 한 줄로 여덟 가지 (비밀값 없이 돈다)

### ③ 웹훅은 **비밀값이 없을 때만** 503 인가

```bash
curl -s -o /dev/null -w "%{http_code}\n" -X POST \
  https://raytok-relay.raytok.workers.dev/pay/webhook \
  -H 'content-type: application/json' -H 'x-portone-signature: nope' -d '{}'
```

| 나온 값 | 뜻 |
|---|---|
| **401** | 비밀값이 **들어 있다**(서명이 틀려서 거절) ← 이것이 정상 |
| **503** | 비밀값이 **없다** → `npx wrangler secret put PORTONE_WEBHOOK_SECRET` 뒤 다시 배포 |
| 200 | 서명 검사를 안 하고 있다 — 배포가 안 된 것이다. 다시 ② 부터 |

### ④ `/usage` 가 선다 — 그리고 **아무나 못 본다**

```bash
curl -s -o /dev/null -w "%{http_code}\n" https://raytok-relay.raytok.workers.dev/usage
```

| 나온 값 | 뜻 |
|---|---|
| **401** | 정상. 사용량은 관리자 비밀값이나 이용권 토큰이 있어야 보인다 |
| 500 | 위 비밀값 표를 다시 본다(`LICENSE_SECRET` 빠짐 쪽) |
| 200 | **문이 열려 있다** — 아무나 사용량을 본다. 이건 바로 알려 주셔야 한다 |

숫자를 직접 보실 때는 관리자 비밀값으로:
`curl -s -H "X-Admin-Secret: <ADMIN_SECRET>" https://raytok-relay.raytok.workers.dev/usage`
(값은 화면에 남으니 남이 보는 자리에서는 치지 않는다.)

### ⑤ V1 결제 확인이 **살아 있나** (B 30, 실결제 1건)

`raytok.kr/buy/` 에서 손님 1일권(3,300원)을 실제 카드로 1건 결제하고 **쿠폰이 나오는지** 본다.
안 나오면 `npx wrangler tail` 에 찍힌 줄로 어디서 막혔는지 바로 보인다:

| 보이는 것 | 뜻 | 할 일 |
|---|---|---|
| 503 `pg_secret_missing` · `why=imp_secret_missing` | V1 열쇠 둘이 없다 | `wrangler secret put IMP_API_KEY` · `IMP_API_SECRET` 뒤 다시 배포 |
| 503 `pg_unavailable` · `why=imp_token` | 열쇠가 틀렸다(포트원이 토큰을 안 준다) | 콘솔의 V1 API Secret 을 다시 복사해 넣는다 |
| 402 `payment_not_verified` · `why=imp_merchant` | 포트원이 아는 주문번호와 우리 번호가 다르다 | 결제창 호출 쪽(`buy/index.html` merchant_uid)을 본다 |
| 402 · `why=imp_amount` | 금액이 다르다 | 상품표와 결제창 금액을 맞춘다 |
| 200 + 쿠폰 | **정상** | 당일 취소(환불)까지 해 본다 |

결제 1건은 **환불까지 같이** 해 둔다 — 심사·장부에 남는 금액을 0 으로 되돌린다.

## 3. 되돌리는 법

**릴레이**(이 배포): Cloudflare 대시보드 → Workers → `raytok-relay` → **Deployments** →
10-16 11:53 (`0d2b7fbc`) → Rollback.
또는 PC 에서 `cd relay && npx wrangler rollback`. 비밀값은 배포와 따로 살아 있어 롤백해도 그대로다.

**정적 사이트**(위 1-2): 그 줄의 `git revert <해시>` → `git push origin main`. 미는 즉시 산다.
되돌릴 것이 여러 줄이면 **최근 것부터** 하나씩(해시가 서로 걸려 있다).

배포가 깨졌을 때 **먼저 볼 것**: `cd relay && npx wrangler tail` 을 켜고 위 ②를 한 번 더 돌린다 —
어느 끝점에서 무엇이 터지는지 그 줄에 뜬다.

## 4. 이 배포가 **하지 않는** 것

- **결제 운영 전환이 아니다.** 구매 화면은 아직 포트원 **테스트 채널**이다(실돈 0).
  운영 키로 바꾸는 순서는 `docs/pg-switchover.md` 한 장 — 그 문서의 ② 가 이 배포와 같은 자리다.
- **앱 빌드와 무관하다.** 앱(LANG-xx)은 EAS 쪽이고 이 배포는 릴레이 하나다.
- `raytok.kr` 정적 사이트는 GitHub Pages 라 **밀면 이미 살아 있다** — 배포할 것이 없다.
