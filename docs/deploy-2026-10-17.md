## 2. 배포 전/후 확인

### ① 배포 전 — `wrangler secret list` 로 **이름만** 본다

| 이름 | 없으면 무엇이 멈추나 |
|---|---|
| `LICENSE_SECRET` | 토큰 서명. 이용권 전부 멈춤 |
| `LICENSE_SALT` | `/license/issue` 가 500 |
| `MINT_PRIVATE_KEY` | 쿠폰이 **시험 키(0)** 로 찍히고 정식 앱이 거부한다 (10-13 12:35 에 지우신 그것) |
| `PORTONE_API_SECRET` | `/pay/complete` → 503 `pg_secret_missing` (결제 발급 멈춤) |
| `PORTONE_WEBHOOK_SECRET` | `/pay/webhook` → 503 `pg_secret_missing` |
| `GOOGLE_TRANSLATE_KEY` | basic 번역 |
| `DEEPGRAM_API_KEY` | Desk 인식 |
| `LLM_API_KEY` | 프로 엔진이 **basic 으로 떨어진다**(멈추지는 않는다, 기록에 `no_key`) |
| `ADMIN_SECRET` | 관리 끝점 |

**있으면 안 되는 것 하나: `PORTONE_API_BASE`.** 있으면 결제 조회가 그 주소로 간다(시험용 자리).
`npx wrangler secret delete PORTONE_API_BASE` — 목록에 보이면 지운다.

조이개(선택, 없으면 기본값): `LLM_DAILY_CAP_USD`(5) · `LLM_TIMEOUT_MS`(2000) · `LLM_PROVIDER`(gemini) ·
`LLM_MODEL` · `TRANSLATE_CAP_CHARS` · `LICENSE_MAX_DEVICES`(1) · `DESK_KEEP_DAYS` · `DESK_HARD_CAP_MIN`.

### ② 배포 뒤 — 한 줄로 여덟 가지 (비밀값 없이 돈다)

```bash
RELAY_URL=https://raytok-relay.raytok.workers.dev npm run e2e:license
```

여덟 줄이 `[PASS]` 면 끝이다. 특히 볼 셋:
- `[6] POST /translate (0x10 없음 → 403 no_package)` — 이용권 문이 선다
- `[7] POST /translate engine:'pro' (0x20 없음 → 403)` — **B 10 이 올라갔다는 뜻**
- `[8] B 7 마이크 질문 → 강사 + 다른 청취자` — **B 7 이 올라갔다는 뜻**

`[FAIL]` 이 나오면 그 줄 번호와 뒤에 붙은 응답을 그대로 REPORT 에 주시면 된다(토큰은 가려 찍힌다).

### ③ 웹훅은 **비밀값이 없을 때만** 503 인가

```bash
curl -s -o /dev/null -w "%{http_code}\n" -X POST \
  https://raytok-relay.raytok.workers.dev/pay/webhook \
  -H 'content-type: application/json' -H 'x-portone-signature: nope' -d '{}'
```

| 나온 값 | 뜻 |
|---|---|
| **401** | 비밀값이 **들어 있다**(서명이 틀려서 거절) ← 이것이 정상 |
| **503** | 비밀값이 **없다** → `npx wrangler secret put PORTONE_WEBHOOK_SECRET` 뒤 다시 배포 |
| 200 | 서명 검사를 안 하고 있다 — 배포가 안 된 것이다. 다시 ② 부터 |

### ④ `/usage` 가 선다 — 그리고 **아무나 못 본다**

```bash
curl -s -o /dev/null -w "%{http_code}\n" https://raytok-relay.raytok.workers.dev/usage
```

| 나온 값 | 뜻 |
|---|---|
| **401** | 정상. 사용량은 관리자 비밀값이나 이용권 토큰이 있어야 보인다 |
| 500 | 위 비밀값 표를 다시 본다(`LICENSE_SECRET` 빠짐 쪽) |
| 200 | **문이 열려 있다** — 아무나 사용량을 본다. 이건 바로 알려 주셔야 한다 |

숫자를 직접 보실 때는 관리자 비밀값으로:
`curl -s -H "X-Admin-Secret: <ADMIN_SECRET>" https://raytok-relay.raytok.workers.dev/usage`
(값은 화면에 남으니 남이 보는 자리에서는 치지 않는다.)

Cloudflare 대시보드 → Workers → `raytok-relay` → **Deployments** → 10-16 11:53 (`0d2b7fbc`) → Rollback.
또는 PC 에서 `cd relay && npx wrangler rollback`. 비밀값은 배포와 따로 살아 있어 롤백해도 그대로다.

배포가 깨졌을 때 **먼저 볼 것**: `cd relay && npx wrangler tail` 을 켜고 위 ②를 한 번 더 돌린다 —
어느 끝점에서 무엇이 터지는지 그 줄에 뜬다.

## 4. 이 배포가 **하지 않는** 것

- **결제 운영 전환이 아니다.** 구매 화면은 아직 포트원 **테스트 채널**이다(실돈 0).
  운영 키로 바꾸는 순서는 `docs/pg-switchover.md` 한 장 — 그 문서의 ② 가 이 배포와 같은 자리다.
- **앱 빌드와 무관하다.** 앱(LANG-xx)은 EAS 쪽이고 이 배포는 릴레이 하나다.
- `raytok.kr` 정적 사이트는 GitHub Pages 라 **밀면 이미 살아 있다** — 배포할 것이 없다.
