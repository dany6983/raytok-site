### ③ 웹훅은 **비밀값이 없을 때만** 503 인가

```bash
curl -s -o /dev/null -w "%{http_code}\n" -X POST \
  https://raytok-relay.raytok.workers.dev/pay/webhook \
  -H 'content-type: application/json' -H 'x-portone-signature: nope' -d '{}'
```

| 나온 값 | 뜻 |
|---|---|
| **401** | 비밀값이 **들어 있다**(서명이 틀려서 거절) ← 이것이 정상 |
| **503** | 비밀값이 **없다** → `npx wrangler secret put PORTONE_WEBHOOK_SECRET` 뒤 다시 배포 |
| 200 | 서명 검사를 안 하고 있다 — 배포가 안 된 것이다. 다시 ② 부터 |

### ④ `/usage` 가 선다 — 그리고 **아무나 못 본다**

```bash
curl -s -o /dev/null -w "%{http_code}\n" https://raytok-relay.raytok.workers.dev/usage
```

| 나온 값 | 뜻 |
|---|---|
| **401** | 정상. 사용량은 관리자 비밀값이나 이용권 토큰이 있어야 보인다 |
| 500 | 위 비밀값 표를 다시 본다(`LICENSE_SECRET` 빠짐 쪽) |
| 200 | **문이 열려 있다** — 아무나 사용량을 본다. 이건 바로 알려 주셔야 한다 |

숫자를 직접 보실 때는 관리자 비밀값으로:
`curl -s -H "X-Admin-Secret: <ADMIN_SECRET>" https://raytok-relay.raytok.workers.dev/usage`
(값은 화면에 남으니 남이 보는 자리에서는 치지 않는다.)

### ⑤ V1 결제 확인이 **살아 있나** (B 30, 실결제 1건)

`raytok.kr/buy/` 에서 손님 1일권(3,300원)을 실제 카드로 1건 결제하고 **쿠폰이 나오는지** 본다.
안 나오면 `npx wrangler tail` 에 찍힌 줄로 어디서 막혔는지 바로 보인다:

| 보이는 것 | 뜻 | 할 일 |
|---|---|---|
| 503 `pg_secret_missing` · `why=imp_secret_missing` | V1 열쇠 둘이 없다 | `wrangler secret put IMP_API_KEY` · `IMP_API_SECRET` 뒤 다시 배포 |
| 503 `pg_unavailable` · `why=imp_token` | 열쇠가 틀렸다(포트원이 토큰을 안 준다) | 콘솔의 V1 API Secret 을 다시 복사해 넣는다 |
| 402 `payment_not_verified` · `why=imp_merchant` | 포트원이 아는 주문번호와 우리 번호가 다르다 | 결제창 호출 쪽(`buy/index.html` merchant_uid)을 본다 |
| 402 · `why=imp_amount` | 금액이 다르다 | 상품표와 결제창 금액을 맞춘다 |
| 200 + 쿠폰 | **정상** | 당일 취소(환불)까지 해 본다 |

결제 1건은 **환불까지 같이** 해 둔다 — 심사·장부에 남는 금액을 0 으로 되돌린다.

## 4. 이 배포가 **하지 않는** 것

- `raytok.kr` 정적 사이트는 GitHub Pages 라 **밀면 이미 살아 있다** — 배포할 것이 없다.

**번역을 강사 폰이 하지 않고, 손님 폰(먼저)과 방(보조)이 한다.**

그걸 못 하는 손님에게는 **방**이 그 언어로 번역해 보낸다. (결정장부 51·43)

| | 무엇 | 어디서 보나 | 배포 뒤 확인 |
|---|---|---|---|
| **B 3** | 방이 손님 언어마다 **한 번** 번역해 **그 언어 손님에게만** 보낸다. 실패하면 「번역 안 됨」을 알린다 | 청취 화면의 번역 줄 | `wrangler tail` 에 `[방코드] room_tr lang= n= chars=` |
| **B 4** | 원고는 **원문으로 미리 올라가고**(`script_src`), 번역은 「다음」 때 + 다음 한 문단 미리. 늦게 들어온 언어도 방이 채운다 | 강사가 원고를 올린 뒤 「다음」 | `script_src paras=` · `room_tr_pre` · `room_tr_late` |
| **B 5** | 강사 화면이 번역문을 **그만 보낸다**. 리포트의 번역문은 강사 폰의 검수 표에서 나온다 | 강사 화면 「다음」 · 끝 화면 리포트 | 리포트 받아 보기(전과 같아야 한다) |

끄면 **손님은 원문을 그대로 본다** — 빈손이 되지 않는다(R-15). 손님 폰 번역(브라우저
「페이지 번역」)은 끄는 것과 무관하게 그대로 된다.
※ `wrangler secret put ROOM_TR` 로도 덮이는지는 **확인하지 않았다** — 위 길로 끈다.

## 돈이 어떻게 변하나 (보고 전 읽을 것)

- 부르는 횟수가 **손님 수가 아니라 언어 수**로 늘고, 같은 (문단·줄, 언어) 짝은 **두 번 사지 않는다**.
- 강사 화면의 「사전 번역」은 **그대로 선택**이다. 돌리면 그 폰에 검수 번역문이 생기고
  `/translate` 를 그만큼 부른다 — 손님에게 가는 번역과는 **별개의 돈**이다.
- 한 번에 번역하는 언어는 **30개**까지. 넘으면 `room_tr_cap` 을 남기고 거기서 멈춘다.

## 실기 목록 — 폰 넷. **「모름」은 막힘이 아니다** (대표님 10-21 11:32)

> *"일단 진행하고 실기에서 확인하자"*

이 기계에는 크로미움뿐이라 웹킷(사파리) 쪽은 **「모름」**이다. 그래도 **멈출 일이 아니다** —
브라우저 번역이 안 되는 폰에서는 **방이 번역해 보내는 보조 길**이 그대로 받쳐 준다(B 3).
즉 어느 폰에서든 **자막은 손님 말로 나온다**. 실기로 가릴 것은 "어느 길로 나왔나"뿐이다.

| 폰·브라우저 | 보는 것 | 지금 |
|---|---|---|
| **안드로이드 크롬** | ① 주소창에 「번역」이 뜨나 ② 자막 줄까지 번역되나 ③ 번역된 글자를 소리가 읽나 | 크로미움에서 ①②③ 통과 — **실기 대기** |
| **삼성 인터넷** | 같은 셋 | **모름** (안 되면 보조 길) |
| **아이폰 사파리** | 같은 셋 (사파리는 「번역」 자리가 주소창 **왼쪽 ⒜ 메뉴**다) | **모름** (안 되면 보조 길) |
| **아이폰 크롬** ★ | 같은 셋 | **모름** (안 되면 보조 길) |

그 말로 소리가 나면 ③ 입니다. 안 되는 폰이 있으면 **그 폰 이름만** 주시면 표를 채웁니다.
